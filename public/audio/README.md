# Audio File

Place your ambient piano loop here as `ambient-piano.mp3`

## Requirements
- Format: MP3
- Duration: ~30-60 seconds (loops seamlessly)
- Volume: Normalized, not too loud
- License: Royalty-free / CC0 / Your own recording

## Recommended Sources
- **Freesound.org** - Search "ambient piano loop" filter by CC0
- **Pixabay Music** - Free for commercial use
- **YouTube Audio Library** - Free attribution-free music
- **Record your own** - Simplest licensing!

## File Naming
The file must be named exactly: `ambient-piano.mp3`

The music toggle button (bottom-right heart icon) will control playback.
